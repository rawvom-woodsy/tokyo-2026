# Image sources and status

This repository is an initial visual prototype for a personal travel planner. 

## Locally hosted photographs in `assets/photos/`

The four locally hosted preview photographs were copied from the public [TGthms/japan-travel-guide](https://github.com/TGthms/japan-travel-guide) project (the repository's code is MIT-licensed; the copyright/license for its photographs was **not separately verified**). Treat these as **temporary design placeholders** and replace or obtain permission before broad publication.

- `tokyo-skyline.jpg` ← `assets/gallery/main/Tokyo.jpg`
- `sumida-sunset.jpg` ← `assets/gallery/medium/birdshapedcloudchasingthesettingsun.jpeg` (Tokyo Skytree, Sumida, August 2024)
- `asakusa-aerial.jpg` ← `assets/gallery/thumbs/viewfromtokyoskytree.jpeg` (Tokyo Skytree view, Sumida, August 2024)
