# Tokyo 2026 Travel Journal

A personal, editorial-style travel planner for Tokyo, October 29–November 7, 2026.

Open `index.html` for the itinerary. Enable GitHub Pages from `main` / root to publish.

## Images
The local `assets/` images are a temporary visual prototype, credited in the site. Official hotel and Tokyo International Film Festival visuals remain linked to their owners rather than rehosted.
